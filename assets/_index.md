# Артефакты проекта

Здесь хранятся графики, схемы, изображения и экспортированные отчёты. Используйте понятные имена и встраивайте файлы в заметки через `![[имя-файла.png]]`.

Рекомендуемый формат имени: `EXP-xxx-краткое-описание.png`. Выбранные графики из EDA notebook автоматически сохраняются как `assets/eda/EDA-NNN.png`. Полные версии больших таблиц сохраняются как `assets/eda/EDA-NNN-table-XX.csv`. Оба типа артефактов связываются с карточками [[eda/findings/_index.md]].

Модели, полные CV-результаты и metadata запусков хранятся отдельно в
[[artifacts/_index.md]], чтобы тяжёлые машинные файлы не попадали в Git вместе
с визуальными материалами Obsidian.
